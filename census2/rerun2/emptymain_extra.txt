# 予測集合への【事後】追加リスト（emptyMainRepos() の事前予測から漏れた repo）
#
# main空 と norm() の大小文字衝突が同時に起きる repo は n_all-(tp+fn) が 1 になり、
# 事前予測から漏れて differ として上がる。差分が「imported fp +1 / all fn +1」の
# 既知シグネチャであることを確認した場合のみ、ここに追記して再判定してよい。
#
# ここに書いた repo の判定は july_main_bug ではなく july_main_bug_late になる。
# 走行中にオラクルを書き換える行為なので、事前予測と必ず区別して集計する。
# 論文には「予測式で N 件を事前特定、事後追加 M 件」と分けて書くこと。
#
# 書式（TAB か2個以上のスペース区切り。3列すべて必須。欠けると読み込み時にエラー）:
#   <repo>  <追加日時ISO8601>  <観測した差分シグネチャと理由>
# 例:
#   foo__bar  2026-08-04T15:00:00Z  imported fp+1 / all fn+1 (norm衝突で予測式が1になり漏れた)
